## Stage boundary and preservation

Only Stage A is implemented here. No root Python application, formula, policy rule, evidence gate, Streamlit configuration or existing regression test is modified. Python stays the authority for financial and policy logic. Money calculations/charts (B), real entitlement conversation (C), and guided FHTB/career/learning (D) each require a separate reviewed implementation and tests.

The existing 80 Python regressions remain the preservation baseline. New API tests additionally verify strict schema boundaries, provenance, auth, input limits, non-echoing error responses, encrypted cross-compatibility and saved benefit/career data. Browser tests exercise the real Next.js → FastAPI path, rather than successful mocked responses.
